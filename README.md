> Professional **maintenance-page** plugin for [e107 CMS](https://e107.org) — 8 Bootstrap 5 templates, multilingual copy editor, integrated user guide.

This repository hosts the **`sitedown_styles`** plugin packaged in the standard e107 drop-in layout, so the GitHub codeload zip can be extracted directly onto an e107 site root.

## 🚀 Quick install

1. Download the latest [release zip](https://github.com/e107-Kanonimpresor/sitedown/releases).
2. Extract on your e107 site root — the plugin lands in `e107_plugins/sitedown_styles/`.
3. Admin Area → **Plugin Manager** → install **Sitedown Styles**.
